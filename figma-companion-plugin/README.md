# ⚡ Figma to Roblox Exporter (Figma Companion Plugin)

This companion Figma plugin allows you to select any UI Frame, Button, or Component in Figma and export it directly to your clipboard with 100% matching properties for Roblox Studio.

---

## 🚀 How to Install in Figma (Takes 10 Seconds)

### Step 1: Open Figma Desktop App
1. Open your Figma design file.
2. Click the **Figma Menu** (top-left logo) or right-click anywhere on the canvas.
3. Go to **Plugins** $\rightarrow$ **Development** $\rightarrow$ **Import plugin from manifest...**

### Step 2: Select the Manifest File
Choose the `manifest.json` file located in:
```
c:\Users\analy\Documents\Antigravity\FigmaToRobloxPlugin\figma-companion-plugin\manifest.json
```

### Step 3: Export Any UI to Roblox
1. Click on any **Frame**, **Component**, or **Card** in your Figma file (e.g. `Frame 1`).
2. Right-click $\rightarrow$ **Plugins** $\rightarrow$ **Development** $\rightarrow$ **Figma to Roblox Exporter**.
3. Click the **"📋 Copy JSON for Roblox"** button.
4. The exact JSON payload is copied to your clipboard!

---

## 🎮 Importing into Roblox Studio

1. Open **Roblox Studio**.
2. Click **"Figma to Roblox"** on your Plugins toolbar.
3. Press `Ctrl + V` inside the JSON box to paste.
4. Click **"⚡ Generate UI in StarterGui"**.
5. Your UI appears in `StarterGui` with exact colors, strokes, corner radii, and bold fonts!
